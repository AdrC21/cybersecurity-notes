## Clase 3.0.1 — ¿Por Qué Debería Tomar Este Módulo?

**Tipo:** 📄 Lectura — Soluciones de Seguridad Protego

### 🎭 Contexto narrativo

Protego está iniciando las pruebas para **Pixel Paradise**. En esta fase de recopilación de información, se pondrán en práctica habilidades de **reconocimiento pasivo y activo** como base para la explotación de vulnerabilidades descubiertas.

### 💡 Ideas clave

- El primer paso de cualquier actor de amenazas al planificar un ataque es **recopilar información sobre el objetivo** → esto se llama **reconocimiento**.
- Los atacantes usan herramientas de escaneo y enumeración junto con información pública de Internet para crear un **expediente sobre el objetivo**.
- El pentester debe replicar exactamente estos métodos para determinar la **exposición real** de las redes y sistemas que intenta defender.

### 🗺️ Hoja de ruta del módulo

```
1. ¿Qué es el reconocimiento? → diferencia entre pasivo y activo
2. Herramientas y técnicas comunes de reconocimiento
3. Proceso de escaneo de vulnerabilidades
4. Cómo funcionan las herramientas de escaneo
5. Análisis de resultados del escaneo → hallazgos útiles
6. Aprovechamiento de la información para la fase de explotación
7. Desafíos comunes al realizar escaneo de vulnerabilidades
```
