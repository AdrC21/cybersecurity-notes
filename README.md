## 🎯 ¿De qué trata este curso?

El panorama digital evoluciona a un ritmo sin precedentes y las amenazas cibernéticas acechan en cada esquina. La resiliencia de la ciberseguridad en el mundo moderno no puede ser solo un complemento — **es una necesidad**.

Este curso está diseñado para preparar al estudiante con un conjunto de habilidades de **Hacker Ético**, brindando una sólida comprensión de la seguridad ofensiva. Al completarlo, el estudiante se convierte en experto en:
- Definir el alcance de una evaluación de seguridad
- Ejecutar pruebas de penetración
- Elaborar informes sobre evaluaciones de vulnerabilidades
- Recomendar estrategias de mitigación

> 💡 El curso es útil tanto para **equipos rojos** (seguridad ofensiva) como para **equipos azules** (seguridad defensiva), ya que comprender la mentalidad del atacante permite implementar mejores controles.
